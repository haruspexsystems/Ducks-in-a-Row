No certificate to download

HTTP 404 Not Found
https://ducksinarow.dev/problems/certificate-unavailable

What it means

This row has no stored certificate to hand out. A request that never became a certificate has none. A row first synced by an older version of Ducks in a Row gains one on the next sync from the certification authority.

What to do

If the row is an issued certificate, wait for the next inventory sync, or start one from the dashboard, then download again.
