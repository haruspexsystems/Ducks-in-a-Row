Problem types

When the Ducks in a Row dashboard refuses a request, its answer is an RFC 9457 problem document whose type is one of the addresses below. Each page says what the problem means and what to do about it.

  • ca-access-denied: CA access denied
  • ca-error: Certificate Authority error
  • ca-unavailable: Certificate Authority is unavailable
  • certificate-already-revoked: Certificate is already revoked
  • certificate-not-revocable: Nothing to revoke
  • certificate-unavailable: No certificate to download
  • invalid-revocation-reason: Invalid revocation reason
  • monitor-mode: Not available in monitor mode
  • revocation-blocked-by-guardrail: Blocked by the TLS certificate guardrail
  • revocation-out-of-scope: Outside the configured revocation scope
  • revocation-target-mismatch: Confirmation does not match this certificate

ACME errors are not listed here. They carry the standard urn:ietf:params:acme:error: types from RFC 8555.
