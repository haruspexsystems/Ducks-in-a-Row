Blocked by the TLS certificate guardrail

HTTP 403 Forbidden
https://ducksinarow.dev/problems/revocation-blocked-by-guardrail

What it means

The dashboard revokes TLS certificates and nothing else. A certificate is in reach only when all of these hold:

  • it has an extended key usage extension, and the extension is not empty;
  • every purpose in it is server authentication or client authentication;
  • its key usage does not include certificate signing or CRL signing;
  • it is not a CA certificate.

A certificate whose capability cannot be read at all is refused too. The response detail says which condition this one failed.

No setting widens this. It is what keeps the product from ever revoking a domain controller certificate, a code signing certificate or the CA's own certificate.

What to do

If you do mean to revoke this certificate, revoke it at the CA in the Certification Authority console.
