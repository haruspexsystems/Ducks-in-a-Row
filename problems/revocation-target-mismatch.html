Ducks in a Row

Confirmation does not match this certificate

HTTP 409 Conflict
https://ducksinarow.dev/problems/revocation-target-mismatch

What it means

The revoke dialog sends the serial number of the certificate you confirmed, and it did not match the certificate the request named. Ducks in a Row refuses rather than guess which one you meant. This usually means the page was out of date.

What to do

Reload the page and revoke again.
