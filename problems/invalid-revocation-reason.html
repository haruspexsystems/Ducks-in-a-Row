Invalid revocation reason

HTTP 400 Bad Request
https://ducksinarow.dev/problems/invalid-revocation-reason

What it means

A revocation must carry one of the RFC 5280 reason codes 0 to 6: unspecified (0), key compromise (1), CA compromise (2), affiliation changed (3), superseded (4), cessation of operation (5) or certificate hold (6). The request carried something else, so nothing was sent to the CA.

What to do

Choose one of the reasons the revoke dialog offers. A script calling the dashboard API directly must send one of the codes above.
