Problem type

Not available in monitor mode

HTTP 403 Forbidden, or 404 Not Found on the ACME administration API
https://ducksinarow.dev/problems/monitor-mode

What it means

This Ducks in a Row server runs in monitor mode. It watches its certification authority: it keeps the certificate inventory, warns before certificates expire, and watches the CA's revocation lists. It never writes to the CA, so it issues no certificates, offers no ACME service, and revokes nothing, from the dashboard or any other way.

The request you made would have written to the CA. It was refused, and nothing was sent to the CA.

What to do

To issue or revoke a certificate, do it at the certification authority, or from a Ducks in a Row server in full mode.

Monitor mode is chosen by a local administrator on the server, never from the dashboard. It is the registry value Mode beside DataDirectory under HKLM\SOFTWARE\Haruspex Systems\Ducks in a Row. To turn issuance on, grant the server's computer account the rights issuance needs (Request Certificates on the CA and Enroll on each template), set the value to full, and restart the service.
