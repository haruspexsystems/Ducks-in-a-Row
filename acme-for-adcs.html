ACME server

An ACME server for the ADCS you already run

Autoenrollment looks after domain joined Windows machines. Linux servers, appliances and anything not domain joined usually get their certificates by hand. Ducks in a Row is one Windows service in front of your ADCS certificate authority that speaks ACME, so those machines request and renew their own certificates from the CA you already run, and the certificates chain to the root you already trust.

Download Read the quickstart

How it works

Ducks in a Row implements RFC 8555, so any standard ACME client works, with no agent or proprietary software on your endpoints. Every certificate template you enable for ACME becomes its own directory:

https://your-server:5001/acme/<template>/directory

A client proves control of a name, the server validates the challenge itself, and then it submits the request to your CA through the CA's own COM interface. The template still decides the key type and the lifetime, and the CA's policy module still has the last word.

  • Challenge types: http-01, dns-01 and tls-alpn-01, and device-attest-01 for managed devices.
  • External account binding: a new install requires a credential to register. A credential can carry a domain namespace, so a team orders only its own names, and revoking it suspends orders from that team's accounts and no one else's.
  • Renewal information (ARI): the server tells clients when to renew. A revoked certificate's window moves into the past, so a client that reads ARI renews at once.
  • No stored server credentials: each machine asks for its own certificate with its own ACME account key.

The clients

The client guide covers certbot, win-acme, Caddy, Traefik, Posh-ACME and cert-manager, with the directory URL, the challenge types and the key and CSR rules. For Kubernetes, see cert-manager and ADCS.

What it needs

  • A domain joined Windows Server 2019, Server 2022 with current updates, or Server 2025, with the ADCS Remote Administration Tools (RSAT-ADCS-Mgmt).
  • For the server's computer account: Request Certificates on the CA and Enroll on each template you expose.
  • Outbound reach from the server to the names it validates: port 80 for http-01, 53 for dns-01, 443 for tls-alpn-01. Clients reach the server on TCP 5001.

What to ask your AD and CA team lists every right and firewall opening in a page you can forward, and the system requirements have the full list.

Part of the free core

The ACME server, all four challenge types and external account binding are part of the free core: free in production, with no limit on certificates, for one CA. Ducks in a Row is source available under the Business Source License 1.1, and it collects no telemetry.
